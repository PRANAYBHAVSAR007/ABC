# Practical 11 — FCFS Scheduling

`fcfs.c` is the complete runnable implementation covering arrival time, burst time, sorting by arrival time, completion time, turnaround time, waiting time, and averages.

Compile:
```bash
gcc -Wall -Wextra -std=c11 fcfs.c -o fcfs
```
Run:
```bash
./fcfs
```

The two smaller files correspond to the manual's earlier sets.
