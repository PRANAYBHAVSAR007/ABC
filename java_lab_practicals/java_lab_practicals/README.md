## 🚀 How to Run Locally

### Prerequisites
- Install **JDK 8 or higher** (JDK 17 or JDK 21 recommended).
- Ensure `javac` and `java` commands are in your system PATH.

### Terminal / Command Line Execution

1. **Navigate to the project root directory**:
   ```bash
   cd java_lab_practicals
   ```

2. **Compile a practical file**:
   ```bash
   javac src/Practical1.java
   ```

3. **Run the compiled class**:
   ```bash
   java -cp src Practical1
   ```

*(Replace `Practical1` with any practical number from `Practical1` to `Practical22`)*

---

## 🌐 Running on Online Compilers

If you don't have JDK installed locally, you can use online compilers like **OnlineGDB**, **JDoodle**, or **Replit**:

1. Open [OnlineGDB Java Compiler](https://www.onlinegdb.com/online_java_compiler) or [JDoodle](https://www.jdoodle.com/online-java-compiler).
2. Copy the contents of any `.java` file inside `src/`.
3. Paste into the editor.
4. Click **Run**.
